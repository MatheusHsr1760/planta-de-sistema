## Analogia das 3 Camadas usando um Mercado

Podemos comparar a arquitetura de um sistema com o funcionamento de um mercado.

**Camada de Apresentação:**  
É a parte que o cliente vê no mercado, como as prateleiras com produtos, os preços exibidos e o caixa onde o cliente interage para pagar. Essa parte é responsável pela interação com o cliente.

**Camada de Negócio:**  
São as regras do mercado. Por exemplo, calcular o valor total da compra, aplicar descontos, verificar promoções ou conferir se o cliente tem saldo para pagar. Essas regras definem como o sistema funciona.

**Camada de Dados:**  
É onde ficam guardadas as informações do mercado, como o estoque de produtos, o preço de cada item e o registro das vendas. Essas informações precisam ser armazenadas para serem usadas depois.

Assim como no mercado cada parte tem sua função, em um sistema de software também é importante separar **o que o usuário vê (Apresentação)**, **as regras de funcionamento (Negócio)** e **as informações armazenadas (Dados)**.
